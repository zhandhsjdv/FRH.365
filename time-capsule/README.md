# ⏳ 时光胶囊 · 使用说明

一个可以把想说的话"交给时间"的小程序：**封存后只能继续添加、不能查看，到达设定时间后自动开启**。

> 本文件夹里的文件名全部是英文，是为了避免中文文件名在不同系统间传输时乱码；文件内容仍是中文，不影响使用。

---

## 一、文件说明

| 文件 | 作用 |
|------|------|
| `dist/time-capsule.exe` | **主程序**，双击即可运行，不需要安装 Python、不需要联网 |
| `index.html` | 前端界面源码，也可以直接用浏览器打开 |
| `launcher.py` | 启动器源码（仅用 Python 标准库，可自行重新打包） |
| `build.bat` | Windows 一键打包脚本 |

---

## 二、怎么运行

### 方式 A：双击 exe（推荐）

双击 `dist/time-capsule.exe` → 弹出黑色命令行窗口 → 默认浏览器自动打开程序界面。

用完直接关闭那个黑色窗口即可退出。

> 为什么是"命令行窗口 + 浏览器"？
> exe 只负责在本机开一个临时网页服务（只监听 127.0.0.1，外部电脑访问不到），界面和加密全部在浏览器里完成。这样既有"双击就能用的程序"，又能保证界面美观、跨系统通用。

### 方式 B：直接双击 HTML

双击 `index.html`，同样可以用。个别旧浏览器在本地文件模式下会禁用加密接口，这时请改用方式 A。

---

## 三、操作流程

1. **封存新胶囊**
   - 填写名称、开启时间（可点 `+10 秒（演示）` 等快捷按钮）
   - 写下想说的话，点「封存胶囊」

2. **密封期间**
   - 在「我的胶囊」中点开它，会看到 🔒 密封状态和倒计时
   - 此时**可以继续输入新内容并封存**，但已有内容完全看不到
   - 每条内容都单独加密存储

3. **时间到后**
   - 程序开着时会自动解锁、撒花提示
   - 关掉后重新打开也会直接显示已开启状态

4. **换电脑用**
   - 在详情页点「📤 导出文件」，得到 `.capsule` 文件
   - 在另一台电脑点「📥 导入胶囊文件」即可继续；内容仍然是加密的

---

## 四、实现原理（简单版）

- **加密**：浏览器原生 AES-GCM（256 位），每条内容用随机 IV 加密，并把开启时间写入认证数据。任何人直接改胶囊文件里的时间，解密都会失败。
- **密封**：密封状态下页面只渲染倒计时层，根本不读取、不显示内容。
- **自动开启**：程序每秒比较一次当前时间和设定时间，到了就自动解密展示。
- **存储**：默认存在浏览器本地（localStorage），也可以导出成独立的 `.capsule` 文件携带。

> 说明：这是**软件时间锁**，时间判断依赖电脑系统时间。修改系统时间可以绕过，适合个人记录、同学演示、学习用途；如果需要防篡改的法律级存证，要用服务器时间戳或可信时间源。

---

## 五、重新打包（可选）

双击 `build.bat` 即可自动重新生成 `dist/time-capsule.exe`，它会先检查/安装 pyinstaller 再打包。

等价命令行：

```bash
python -m PyInstaller --onefile --console --clean --name time-capsule \
  --add-data "index.html;." --distpath dist --workpath build launcher.py
```
