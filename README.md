# FRH.365

本仓库存放 **⏳ 时光胶囊** 程序。

一个可以把想说的话"交给时间"的小程序：**封存后只能继续添加、不能查看，到达设定时间后自动开启**。

## 目录结构

```
时光胶囊/
├── 时光胶囊.html      # 前端界面（直接双击即可用）
├── 启动器.py          # 本地服务启动器源码
├── 使用说明.md        # 中文使用说明
├── 打包.bat           # Windows 一键打包脚本
└── dist/
    └── 时光胶囊.exe   # 已打包好的独立程序（双击即用）
```

## 快速开始

- **最简单**：双击 `时光胶囊/dist/时光胶囊.exe`，浏览器自动打开界面。
- **有 Python**：双击 `时光胶囊/时光胶囊.html` 也能直接用。
- **重新打包**：双击 `时光胶囊/打包.bat`，自动生成 exe。

详细操作见 [时光胶囊/使用说明.md](时光胶囊/使用说明.md)。

## 功能

1. 写下内容，自由选择开启时间（支持快捷预设）。
2. 密封期间可继续添加内容，但完全无法查看已有内容。
3. 时间到达后自动开启并展示全部记忆。
4. 支持导出/导入 `.capsule` 文件，换电脑也能用，内容保持加密。

加密采用浏览器原生 AES-GCM 256 位；时间锁为软件实现，依赖本机系统时间。
